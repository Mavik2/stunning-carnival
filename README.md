# stunning-carnival
Игра для закрепления школьных знаний. Мини приложение на платформе макс вк
Чтобы запустить необходимо 
  1. Скачать все файлы
  2. Распаковать архивы
  3. Папки "Математика", "Русский язык", "Физика" поместить в одну общую папку под названием "Уровни"
игра запускается по ссылке https://resplendent-semifreddo-08f6c0.netlify.app/
возможно для перехода по ссылке потребуется VPN
